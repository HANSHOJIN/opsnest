# OpsNest Roadmap

这份路线图记录已经确认的开发方向。Alpha 阶段优先完成真实功能和交互闭环；正式版再集中进行安全加固、权限细化和回滚体系建设。

## P0：当前 Agent 基础能力

- AgentRun 根据命令结果持续调整下一步
- 执行结果的自然语言总结
- 服务器记忆与会话上下文
- 命令失败后的有限恢复
- 命令、结果和审批记录的本地审计

## P1：服务器文件管理

目标：在 SSH 会话之外，提供类似 Workbench 的文件管理能力，让新手不用手写 `scp`、`sftp` 或 `cp` 命令。

第一阶段：

- 浏览当前目录和目录树
- 查看文件名、大小、修改时间和权限
- 返回上级目录、进入目录
- 文本文件预览
- 文件搜索
- 上传文件到当前目录
- 从服务器下载文件
- 显示上传/下载进度和失败原因

第二阶段：

- 创建目录
- 重命名文件和目录
- 删除文件和目录
- 编辑并保存文本文件
- 文件权限查看与修改
- 压缩与解压

正式版安全增强：

- 删除、覆盖、权限修改的分级确认
- 文件内容发送给模型前的精细化控制
- 完整权限模型和本地审计
- 大文件传输取消、重试和恢复
- 文件版本快照与回滚

## P1：服务器卡片快捷安装

目标：在服务器 Dashboard 卡片中提供“快捷安装”菜单，把常用软件安装变成可审查的任务，而不是直接执行隐藏命令。

首批候选：

- Docker
- Git
- Nginx
- Caddy
- Node.js
- Python
- Certbot
- `docker compose`
- 常用监控工具：`htop`、`btop`

Alpha 阶段交互流程：

```text
服务器卡片
  → 快捷安装
  → 选择软件
  → 检测系统与包管理器
  → 展示安装计划和预计影响
  → 用户批准
  → 执行安装
  → 验证版本与服务状态
  → 保存结果到服务器记忆
```

实现要求：

- 根据 Debian、Ubuntu、CentOS、Alpine 等系统选择安装策略
- 安装前检查系统版本、权限、磁盘空间和网络
- 明确使用 `apt`、`dnf`、`yum`、`apk` 或官方安装源
- 显示将执行的命令，但不要求新手理解命令
- 安装完成后自动验证版本和服务状态
- 失败时显示失败阶段，方便继续调试
- 每个安装项使用任务模板，避免完全依赖模型自由生成

正式版再补充安装审批、权限细分、回滚和更严格的风险策略。Alpha 阶段重点是先把快捷安装流程跑通。

## 已有基础能力

- 保存服务器会话：主机地址、SSH 端口、用户名、认证方式和终端会话可持久保存
- 重启后恢复服务器列表、会话记录和本地聊天记录
- 服务器卡片与 SSH 会话支持一键进入

## P1：SSH 隧道与网络转发

目标：借鉴 PuTTY 的端口转发能力，把 SSH 隧道做成可视化配置，而不是要求用户记住 `ssh -L`、`ssh -R` 或 `ssh -D` 参数。

第一阶段：

- 本地端口转发：访问远程服务器内网服务
- 远程端口转发：将本地服务暴露到远程服务器
- 动态 SOCKS5 转发：作为本地代理使用
- 隧道配置保存到服务器会话
- 显示隧道连接状态、监听端口和目标地址
- 支持启动、停止和重连隧道

后续扩展：

- 跳板机与多级 SSH 连接
- 常用服务模板，例如 MySQL、Redis、Web 面板和 Docker API
- 在服务器卡片上显示已启用的隧道

## P1：服务器 Cron 管理与展示

原则：Cron 任务运行在每台服务器自己的 `crond` 或 `systemd timer` 中，OpsNest 不在本机运行调度器。OpsNest 只通过 SSH 读取、展示和管理服务器上的任务。

界面位置：左侧导航中放在“任务记录”上方，作为独立的“定时任务”菜单。

任务来源：

- 服务器总管创建跨服务器任务，并通过 SSH 写入对应服务器
- 用户在定时任务页面创建任务，并选择目标服务器
- 子服务器会话创建当前服务器的任务

权限范围：

- 总管和用户：可以查看和管理所有服务器的任务
- 子服务器会话：只能查看和管理当前服务器的任务

第一阶段：

- 读取服务器现有的用户 Cron、系统 Cron 和 systemd timer
- Cron 表达式和常用周期选择器
- 任务名称、目标服务器、执行命令和启用状态
- 通过 SSH 创建、编辑、暂停、恢复和删除服务器上的任务
- 显示服务器报告的下次执行时间和最近一次执行结果
- 将服务器返回的执行结果写入任务记录，并标注服务器名称、任务名称、开始时间、结束时间、退出状态和输出
- 任务执行失败时保留完整错误输出，方便 Agent 和用户继续排查

后续扩展：

- 由总管通过自然语言创建定时任务
- 任务执行前后调用服务器记忆和 AgentRun
- 多服务器并行配置与分批配置
- 失败通知和执行结果摘要

## P2：文件与任务联动

- “上传并部署这个文件”任务
- “查看这个配置文件并解释”任务
- “修改配置、备份原文件、验证并回滚”任务
- 文件变更前后对比
- 部署任务时间线

## P2：更完整的 Agent 工具层

- 将文件操作、服务操作、软件安装收敛为参数受限工具
- 工具声明风险等级、权限要求和回滚能力
- 动态工具发现，而不是一次暴露全部工具
- 支持任务暂停、恢复和取消
- 支持任务中途修改计划

## 正式版安全加固阶段

- 细粒度权限和风险策略
- 操作审批与二次确认
- 配置和文件回滚
- 更完整的凭据保护与审计
- 批量操作保护

## 暂不纳入近期范围

- Kubernetes 全面管理
- 无人值守批量生产变更
- 云端凭据同步
- 团队协作和多租户
- 自动修改防火墙和安全组
- 自动删除、格式化和数据库破坏性操作
